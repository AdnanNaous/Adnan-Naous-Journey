# Progress

This directory records evidence-based progress without exaggerating achievements.

Use dated files such as `YYYY-MM.md` for regular logs and descriptive milestone files when useful. Link each claim to repository evidence, such as a learning entry, tested challenge, project, or review.

Record incomplete work, blockers, corrections, and changed plans honestly. Time spent may provide context, but demonstrated understanding and reproducible results are stronger evidence. Use [`../templates/progress-entry.md`](../templates/progress-entry.md).
