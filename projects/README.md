# Projects

This directory contains self-contained projects that apply learned concepts.

Use `projects/<project-name>/`. Every project should have its own `README.md` describing the problem, goals, scope, design decisions, setup, usage, validation, limitations, and learning outcomes. Keep project-specific source code, tests, and documentation together.

Projects must not be marked complete without evidence. Use [`../templates/project.md`](../templates/project.md) as a starting point.
