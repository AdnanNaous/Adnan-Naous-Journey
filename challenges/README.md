# Challenges

This directory records practice exercises by subject.

Use `challenges/<subject>/<challenge-name>/`. Preserve the original attempt when educationally valuable, then document the correction and final reasoning. Include the prompt or a lawful summary, constraints, complexity analysis, validation, and source attribution.

Do not replace a genuine attempt with a polished solution that hides the learning process. Start with [`../templates/challenge.md`](../templates/challenge.md).
