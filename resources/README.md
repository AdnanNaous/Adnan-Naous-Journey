# Resources

This directory contains evaluated learning resources organized by subject.

Use `resources/<subject>/<resource-name>.md`. Record the author or organization, stable link or publication information, relevant topics, why the resource is useful, limitations, completion status, and notes. Never invent a source or imply that a resource was completed when it was only discovered.

Prefer primary documentation, standards, textbooks, and reputable courses. Use [`../templates/resource-review.md`](../templates/resource-review.md).
