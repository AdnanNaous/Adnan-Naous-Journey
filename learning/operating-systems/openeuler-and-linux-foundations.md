## Academic Explanation

- **openEuler:** An open-source operating-system project designed for digital-infrastructure scenarios such as servers, cloud, edge, and embedded systems.
- **RAG:** Retrieval-augmented generation retrieves relevant information from a knowledge base to provide additional context to a language model. openEuler Intelligence includes RAG-based knowledge question answering.
- **Linux shell:** A command-line interface that interprets commands and lets users interact with the operating system.
- **Virtual machine:** A software-defined computer environment that runs a guest operating system using virtualized hardware resources.
- **Vim:** A modal text editor commonly used in terminal environments for creating and editing text files.
