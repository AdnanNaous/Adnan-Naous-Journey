# Learning

This directory contains durable learning material organized by computer science subject.

Use `learning/<subject>/<topic>.md`, with lowercase kebab-case names. Create a subject directory only when real content is ready. Examples include `data-structures-and-algorithms`, `operating-systems`, `databases`, and `computer-networks`.

Each topic should include learning objectives, prerequisites, an explanation in the learner's own words, worked examples, mistakes and corrections, validation status, sources, and next steps. Start with [`../templates/learning-entry.md`](../templates/learning-entry.md).

Do not organize content by AI tool or store raw conversations. Convert useful discussion into independent subject documentation.
